# PHASE 1 — TECHNICAL SEO FOUNDATION

# 1. DOMAIN & INDEXING

## Checklist

- [ ] Connect domain to Google Search Console
- [ ] Verify ownership
- [ ] Submit sitemap.xml
- [ ] Submit robots.txt
- [ ] Enable HTTPS
- [ ] Redirect www → non-www OR vice versa
- [ ] Set canonical domain
